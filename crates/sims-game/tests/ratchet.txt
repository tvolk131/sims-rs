# The screenshot ratchet's scenes (tests/ratchet.rs reads them). Each
# `[name]` opens a scene; then one `key = value` line each:
#
# - about: what the screenshot shows;
# - tick: our tick, the lot's ticks since the load;
# - zoom (far, medium or near), rotation, level, origin (the camera's,
#   x then y) and walls (up, cutaway or down);
# - paused and strip: whether the original was paused and its panel's
#   strip open (yes or no);
# - original: the screenshot's plain file name in SIMS_RATCHET (no
#   folder; with links resolved it stays in that folder) and its SHA-256;
# - ours: the SHA-256 of our frame's 8-bit colours;
# - leave_out: a rectangle (left, top, right, bottom; right and bottom
#   outside it) and why it is left out, one line each;
# - floors: for each class with pixels in the frame, the share of
#   pixels that must match, in percent with two decimals, at most
#   100.00. A new scene has `floors = none` and `ours = none`, both;
#   SIMS_RATCHET_NEW=<name> sets both. Once they are set, its name goes
#   in the test's BASELINE list, and a baseline scene is never new again.
